# Data Analytics Portfolio

A collection of data analytics and visualization projects demonstrating my skills in SQL, Python, R, Tableau, statistical analysis, and data visualization.

## Projects

### Retail Sales SQL Analysis
Analyzed over 541,000 online retail transactions using PostgreSQL to explore revenue, top-selling products, customer spending, monthly sales trends, and sales by country.

**Skills:** SQL, PostgreSQL, Data Analysis

### Student Success Logistic Regression
Used R and logistic regression to analyze student performance data and explore factors associated with student success.

**Skills:** R, Logistic Regression, Statistical Analysis

### Python Data Structures Project
Developed a Python project demonstrating the use of data structures and programming techniques for organizing and processing data.

**Skills:** Python, Data Structures, Programming

### Titanic Tableau Dashboard
Created an interactive Tableau dashboard to analyze Titanic passenger data and identify patterns in passenger survival.

**Skills:** Tableau, Data Visualization, Dashboard Design
